# Same-Day Launch Checklist

## Build
- [ ] Read the README and run the app locally.
- [ ] Confirm the dashboard displays the demo-data warning.
- [ ] Inspect all three creative concepts.
- [ ] Run the synthetic ML experiment and read its limitations.
- [ ] Run `pytest -q`.
- [ ] Fix obvious errors and remove personal data / local paths.

## Customize
- [ ] Add your real professional contact email and portfolio handle.
- [ ] Replace generic copy with your own explanation of the project.
- [ ] Keep the fictional/demo disclosure visible.
- [ ] Add licensed or self-created product imagery only after checking permission.
- [ ] Do not add invented results, clients, certifications or testimonials.

## Publish
- [ ] Create a GitHub repository with a descriptive name.
- [ ] Do not commit `.venv`, secrets, tokens, private client data or customer records.
- [ ] Push `app.py`, `metrics.py`, `data`, `docs`, `creative_samples`, `experiments`, `tests`, and `requirements.txt`.
- [ ] Deploy on Streamlit Community Cloud if desired; follow its current official instructions.
- [ ] Test the public link in a private/incognito browser window.
- [ ] Include one clear contact method and a sentence explaining the project is a demonstration.
